Instructions to run the Game: -
1. Install Raylib (This repo was updated to run of Raylib 5.5) from the Official Website https://www.raylib.com/ and run the exe application.
2. Keep the default path and settings.
3. Download or pull this repository anywhere and run the main application.
4. Use the numpad to play the game.

The game is a fun ball-based platformer that also focuses on improving arithmetic skills and reaction time. It is designed to be both enjoyable and educational, making it different from conventional games.
